ROOT4 / ROOTKIT

같은 규칙 위에서,
더 빠르고 자유롭게.

Build Faster, Create Freely.

ROOTKIT은 ROOT4가 일하는 방식과 자체 디자인시스템을 담은 키트입니다. 기본 요소를 직접 조합해 보고, 규칙 몇 가지로 얼마나 다양한 결과가 나오는지 확인해 보세요.

01 Work Process 02 Playground 03 Library

01 / Work Process

정해진 순서 위에서,
매번 새롭게 설계합니다.

ROOT4는 다섯 단계로 프로젝트를 진행합니다. 단계를 누르거나 마우스를 올리면 그 단계에서 하는 일과 쓰는 방법이 펼쳐집니다.

    02 / RootKit Playground

    직접 바꿔 보면,
    규칙의 힘이 보입니다.

    왼쪽에서 간격, 상태, 형태, 색을 바꿔 보세요. 오른쪽 화면이 바로 바뀝니다. 값 몇 가지를 조합하는 것만으로 결과가 이렇게 달라집니다.
