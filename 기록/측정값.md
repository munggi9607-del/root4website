# 시안 측정값

2026-11-17, 시안 사이트(https://rootfour-1.vercel.app/)에서 **화면에 실제로 보이는 요소**의 계산된 스타일을 잰 기록입니다. 규칙이 아니라 근거입니다. 규칙은 DESIGN.md에 있습니다.

## 시안 코드 상태

- CSS 변수가 없습니다. 모든 값이 직접 입력되어 있습니다.
- 인라인 스타일시트 하나, 규칙 945개, 서로 다른 색 값 580개. 숨겨진 옛 홈 화면(`#home`) 스타일이 많이 남아 있어 그대로 토큰으로 옮길 수 없습니다.
- 다크 테마는 `body.studio-dark` 클래스로 켭니다.
- 글꼴: Google Fonts `DM Sans`(400–700), `Noto Sans KR`(400–900). 일부에 Georgia, `Root4 Fraunces`(세리프).
