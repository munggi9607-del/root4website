### 정리하면서 정한 것 (2026-11-17 사용자 확정)

| 주제 | 결정 | 이유 |
|---|---|---|
| 제목 글꼴 | 모두 DM Sans. Georgia 세리프 제목 안 씀 | 시안에서 세리프 제목은 `Project Board` 하나, 나머지는 sans |

| 모서리 | 5·6 → 6, 15·16 → 16, 13 → 12, 30 → pill | 비슷한 값 통합 |
| 간격 | 4 배수 9단계 | 시안 간격이 3, 5, 7, 9, 14, 15, 17 등 불규칙 |
| 아바타 바탕 | 회청 → `--surface-control` | 강조색 통일 |
| 다크 테마 값 | 측정한 값: page, panel, rail, control, border, text-primary, text-tertiary. 측정 못 해 정한 값: text-secondary `#C3CCD6`, 보라 위 글자 `#A48EF0`, accent-subtle 보라 18% | 시안 About은 다크에서도 흰 면이 남아 측정할 수 없었음 |

| 버튼 hover·disabled | 계약에 정의 | 시안에 상태가 거의 없음 |

## 2026-11-17 합치기 준비

| 주제 | 결정 | 이유 |
|---|---|---|
| 구현 방식 | 순수 HTML/CSS/JS, 빌드 없음 | 시안이 HTML 한 장. 팀원 누구나 열어 고칠 수 있고 Vercel에 그대로 올림 |
| 저장소 위치 | design-system 폴더가 그대로 저장소·사이트 루트 | 이미 공유한 폴더 경로를 바꾸지 않으려고 |
| AppShell | `shared/appshell.css`·`appshell.js`로 한 벌만 | 각자 그리면 화면마다 달라짐 |
| 메뉴 주소 | `/projects/` `/about/` `/community/` `/archive/` `/contact/`, 원본은 `shared/routes.js` | 주소를 한 곳에서만 바꾸기 위해 |
| 임시 연결 | Projects·About은 시안(`#projects`, `#team`), 나머지는 각 폴더의 '준비 중' 화면 | 시안에 화면이 있는 메뉴만 시안으로 |
| Git | 규칙 문서만 먼저. `menu/{id}` 브랜치, `main`은 리드만 합침 | Git이 아직 설치되지 않음 |

## 2026-11-25 메뉴 이름·순서

| 주제 | 결정 | 이유 |
|---|---|---|
| Community 이름 | **RootKit**으로 바꿈. id·폴더·주소·브랜치도 `rootkit` (`/rootkit/`, `menu/rootkit`) | 이름과 주소를 같은 말로 맞춤. 바꿀 때 community 브랜치에 작업이 없었음 |
| 메뉴 순서 | Projects · About · Archive · RootKit · Contact | RootKit을 Archive 아래에 둠 |
| RootKit 내용·담당 | ROOT4 디자인시스템 활용법을 소개하는 페이지. 담당 혜린(병하에서 변경). 임시 메뉴 표시를 뺌 | 사용자 지정 |
| 프로젝트 상세 | 팝업 → 페이지 `/projects/detail/?p=번호`. 카드 위에 프로젝트 색이 덮인 뒤 화면 전체로 커지는 전환, **GNB 없음**(전용 상단 바), **사이트 색 대신 프로젝트 고유색**, 왼쪽 목차 앵커, 패럴렉스. 화면 틀 D(예외 화면) | 사용자 요청. 보고 후 확인받음. 직전의 'GNB 유지' 안은 같은 날 대체 |
| 프로젝트 상세 구성 | 사용자가 주는 비주얼·설명글에 맞춰 **프로젝트마다 목차를 다르게**(4–7개, 처음 OVERVIEW·끝 NEXT). 비주얼을 화면 가득 보여 주는 패럴렉스 영역은 **한 페이지에 1–2곳**(stage 최대 1 + full). 가이드: screens/projects-detail.md | 사용자 지정 |
