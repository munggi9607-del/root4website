# 화면 브리프 템플릿

새 화면을 만들기 전에 이 템플릿을 복사해 `screens/{메뉴}.md`를 채웁니다. 이미 있는 메뉴 브리프(community.md 등)는 이 형식으로 되어 있으니, 자기 화면 브리프의 빈칸만 채우면 됩니다.

---

```markdown
# {메뉴 이름} 화면

담당: {이름}
상태: 브리프 작성 중 / 확인 대기 / 구현 중 / 리뷰 / 완료

## 1. 이 화면은 무엇인가
한두 문장. 사용자가 이 화면에 왜 오는가.

## 2. 핵심 행동 (하나)
사용자가 이 화면에서 꼭 하는 일 하나. 주 버튼이 이 행동이 됩니다.

## 3. 본문 배치
00-화면-틀.md의 A(작업 공간) / B(읽는 페이지) / C(집중 페이지) 중 하나와 이유.

## 4. 섹션 구성 (위에서 아래로)
| 순서 | 섹션 | 쓰는 컴포넌트 | 내용 |
|---|---|---|---|
| 1 | 머리 | PageHead(hero/page) | 아이브로우 / 제목 / 설명 문구 |
| 2 | | | |

## 5. 적용할 규칙
DESIGN.md와 계약에서 이 화면에 해당하는 규칙을 골라 적습니다.

## 6. 규칙에 없어서 임의로 정한 것
새 컴포넌트, 새 토큰, 정의되지 않은 상태 등. **확인 전까지 구현하지 않습니다.**

## 7. 규칙과 요구사항이 부딪히는 것
예: 시안은 9px인데 최소 11px 규칙, 상태 색이 필요한데 정의 없음.

## 8. 빈 상태 · 오류 · 로딩
데이터가 없을 때, 실패했을 때, 불러오는 중에 무엇을 보여주는가.

## 9. 모바일
데스크톱과 달라지는 것.

## 10. 완료 기준
- [ ] README의 "완료 전 확인" 통과
- [ ] 이 화면만의 기준:
```
