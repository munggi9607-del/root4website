# 화면 틀

모든 메뉴 화면이 공유하는 바깥 틀과 본문 배치 방식입니다. 새 화면은 여기서 **본문 배치 하나를 고르는 것**부터 시작합니다.

## 바깥 틀

[AppShell](../components/AppShell.md)이 그립니다. 화면에서 다시 만들지 않습니다. 각 메뉴 폴더의 `index.html`에 이미 연결되어 있으니 `<main>` 안만 만듭니다([합치기-규칙.md](../합치기-규칙.md)).

| | 데스크톱 ≥1051 | 태블릿 761–1050 | 모바일 ≤760 |
|---|---|---|---|
| 헤더 | 68, 위 | 68, 위 | 56, 위 고정 |
| 메뉴 | 왼쪽 레일 82 | 왼쪽 레일 82 | 하단 탭바 62 고정 |
| 본문 시작 | 헤더 아래, 레일 오른쪽 | 같음 | 헤더 아래, 탭바 위로 62 비움 |
| 본문 바탕 | `--surface-page` 또는 `--surface-panel` | 같음 | 같음 |

## 본문 배치 네 가지

### A. 작업 공간 (Workspace) — Projects

```
┌ Rail ┬ Panel 316 ──────┬ Canvas ─────────────────────────┐
│      │ 대화·컴포저       │ PageHead(page) + 필터            │
│      │ --surface-panel  │ 보드 / 목록 (--surface-page)     │
└──────┴─────────────────┴─────────────────────────────────┘
```

- 패널은 오른쪽에 1px `--border-default` 선, 그림자 없음.
- 태블릿에서는 패널을 닫을 수 있게(접기 버튼) 합니다.
- 모바일에서는 패널이 아래에서 올라오는 시트가 되고, 본문은 PageHead + Tabs(Board/List) + 카드 목록입니다.

### B. 읽는 페이지 (Editorial) — About, Archive, RootKit

```
┌ Rail ┬ 본문 (최대 1140, 좌우 32) ─────────────────────────┐
│      │ PageHead(hero 또는 page)                            │
│      │ ── 1px 선 ──                                        │
│      │ 섹션: PageHead(section) + 내용 (카드 그리드·탭 등)   │
│      │ 섹션 …                                              │
│      │ (선택) 맨 아래 Composer: "팀에게 물어보기"            │
└──────┴─────────────────────────────────────────────────────┘
```

- 바탕 `--surface-panel`. 섹션 사이 `--space-56`, 섹션 구분은 1px `--border-default` 선.
- 카드 그리드: 데스크톱 3열, 태블릿 2열, 모바일 1열. 사이 `--space-16`.
- 데스크톱 hero는 왼쪽 제목 / 오른쪽 설명 2열이 됩니다.

### C. 집중 페이지 (Focus) — Contact

```
┌ Rail ┬ 본문 가운데, 최대 640 ────────────────┐
│      │ PageHead(hero)                       │
│      │ 입력 (TextField, Chip)                │
│      │ 주 버튼 하나 + 도움말                   │
└──────┴──────────────────────────────────────┘
```

- 바탕 `--surface-page` 위에 `Card panel` 하나, 또는 바탕 `--surface-panel` 한 단.

### D. 쇼케이스 (Showcase) — 프로젝트 상세 · **예외 화면**

GNB(AppShell)와 사이트 색 시스템을 쓰지 않는 유일한 화면입니다(2026-11-25 사용자 확정).

```
┌ 상단 바 56: ROOT4 / 프로젝트명 ··········· INDEX │ NEXT │ × ┐
├ 목차 136 ┬ 본문 (최대 1140, 좌우 40) ─────────────────────┤
│ 01 OVERVIEW │ 01 Overview: 제목 display-lg │ 대표 사진        │
│ 02 CONCEPT  │   소개(heading-lg · 문단 · 정보)               │
│ 03 PROCESS  │ 02 Concept: 한 문장 띠 (흐린 사진 + 패럴렉스)  │
│ 04 VISUAL   │ 03 Process: 장면 ×3 (사진 7 : 글 5, 번갈아)     │
│ 05 NEXT     │ 04 Visual: 사진 3장, 서로 다른 속도             │
│             │ 05 Next: 다음 프로젝트 카드(그 프로젝트 색)     │
└─────────────┴───────────────────────────────────────────────┘
```

- **들어오기:** 보드에서 카드를 누르면 카드 사진이 커지며 화면을 덮고 프로젝트 색으로 채워진 뒤(0.65초) 상세로 넘어갑니다. 상세는 같은 색 덮개가 걷히며 시작합니다.
- **색:** `--project-bg`(바탕), `--project-fg`(글자, 대비 4.5:1 이상), `--project-muted`·`--project-line`(글자색을 옅게). 값은 `projects/projects-data.js`의 `color`·`text`. 원색 바탕(대비 7:1 미만)에서는 옅은 글자를 쓰지 않고 글자색 그대로 씁니다. 사이트 다크 모드와 상관없이 고정입니다.
- **그대로 쓰는 토큰:** 글꼴, 글자 크기 단계, 간격, 모서리, 그림자, 모션.
- **목차:** 누르면 그 섹션으로 이동(앵커, 상단 바 아래에 맞춤), 스크롤 위치에 맞춰 현재 항목에 밑줄. 모바일에서는 상단 바 아래 가로 한 줄.
- **버튼:** primary(글자색 바탕) `다음 프로젝트 ↗` 하나, ghost `← 보드로 돌아가기`.
- **패럴렉스:** 사진은 틀보다 24% 크게 두고 속도 0.1–0.2, 글은 0.05 이하. `prefers-reduced-motion`이면 확대 전환·덮개·패럴렉스·나타나기 모두 끄고 바로 이동합니다.
- 프롬프트 입력(Composer)·대화 패널은 두지 않습니다.
- 다른 메뉴에서 이 틀을 쓰려면 보고합니다.

## 모든 화면 공통으로 들어가는 것

- PageHead 하나(화면 맨 위)
- 레일의 현재 메뉴 active
- 다크 테마에서 깨지지 않을 것
- 화면 맨 아래 탭바(모바일)에 가리지 않도록 아래 여백 62 + `--space-24`
