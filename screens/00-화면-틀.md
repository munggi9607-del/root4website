# 화면 틀

모든 메뉴 화면이 공유하는 바깥 틀과 본문 배치 방식입니다. 새 화면은 여기서 **본문 배치 하나를 고르는 것**부터 시작합니다.

## 바깥 틀

[AppShell](../components/AppShell.md)이 그립니다. 화면에서 다시 만들지 않습니다. 각 메뉴 폴더의 `index.html`에 이미 연결되어 있으니 `<main>` 안만 만듭니다([합치기-규칙.md](../합치기-규칙.md)).

| | 데스크톱 ≥1051 | 태블릿 761–1050 | 모바일 ≤760 |
|---|---|---|---|
| 헤더 | 68, 위 | 68, 위 | 56, 위 고정 |
| 메뉴 | 왼쪽 레일 82 | 왼쪽 레일 82 | 하단 탭바 62 고정 |
| 본문 시작 | 헤더 아래, 레일 오른쪽 | 같음 | 헤더 아래, 탭바 위로 62 비움 |
| 본문 바탕 | `--surface-page` 또는 `--surface-panel` | 같음 | 같음 |

## 본문 배치 세 가지

### A. 작업 공간 (Workspace) — Projects

```
┌ Rail ┬ Panel 316 ──────┬ Canvas ─────────────────────────┐
│      │ 대화·컴포저       │ PageHead(page) + 필터            │
│      │ --surface-panel  │ 보드 / 목록 (--surface-page)     │
└──────┴─────────────────┴─────────────────────────────────┘
```

- 패널은 오른쪽에 1px `--border-default` 선, 그림자 없음.
- 태블릿에서는 패널을 닫을 수 있게(접기 버튼) 합니다.
- 모바일에서는 패널이 아래에서 올라오는 시트가 되고, 본문은 PageHead + Tabs(Board/List) + 카드 목록입니다.

### B. 읽는 페이지 (Editorial) — About, Community, Archive

```
┌ Rail ┬ 본문 (최대 1140, 좌우 32) ─────────────────────────┐
│      │ PageHead(hero 또는 page)                            │
│      │ ── 1px 선 ──                                        │
│      │ 섹션: PageHead(section) + 내용 (카드 그리드·탭 등)   │
│      │ 섹션 …                                              │
│      │ (선택) 맨 아래 Composer: "팀에게 물어보기"            │
└──────┴─────────────────────────────────────────────────────┘
```

- 바탕 `--surface-panel`. 섹션 사이 `--space-56`, 섹션 구분은 1px `--border-default` 선.
- 카드 그리드: 데스크톱 3열, 태블릿 2열, 모바일 1열. 사이 `--space-16`.
- 데스크톱 hero는 왼쪽 제목 / 오른쪽 설명 2열이 됩니다.

### C. 집중 페이지 (Focus) — Contact

```
┌ Rail ┬ 본문 가운데, 최대 640 ────────────────┐
│      │ PageHead(hero)                       │
│      │ 입력 (TextField, Chip)                │
│      │ 주 버튼 하나 + 도움말                   │
└──────┴──────────────────────────────────────┘
```

- 바탕 `--surface-page` 위에 `Card panel` 하나, 또는 바탕 `--surface-panel` 한 단.

## 모든 화면 공통으로 들어가는 것

- PageHead 하나(화면 맨 위)
- 레일의 현재 메뉴 active
- 다크 테마에서 깨지지 않을 것
- 화면 맨 아래 탭바(모바일)에 가리지 않도록 아래 여백 62 + `--space-24`
