# Archive 화면 (신규)

담당: 혜린
상태: 브리프 작성 중

> 시안 안내 다이얼로그의 제목이 `아카이브 / 디자인시스템`입니다. 그래서 이 화면은 **지난 작업 기록**과 **ROOT4 디자인시스템 소개**를 함께 담는 곳으로 봅니다. **고정**은 디자인시스템이 정한 것, **제안**은 담당자가 바꿔도 되는 출발점입니다.

## 1. 이 화면은 무엇인가

제안: 끝난 프로젝트와 실험을 연도별로 남기고, ROOT4가 화면을 만들 때 쓰는 디자인시스템(색, 글자, 컴포넌트)을 보여주는 곳.

## 2. 핵심 행동

제안: 지난 작업을 연도·분류로 찾아 연다.

## 3. 본문 배치

**고정:** B. 읽는 페이지.

## 4. 섹션 구성

| 순서 | 섹션 | 컴포넌트 | 내용 |
|---|---|---|---|
| 1 | 머리 | PageHead hero | **고정** 아이브로우 `ROOT4 / ARCHIVE`, 제목 `아카이브`로 시작(제안: `지나온 작업이<br>다음 경험의 바탕이 됩니다.`) |
| 2 | 보기 전환 | Tabs segmented | **고정** `Work` / `Design system` |
| 3a | Work | Chip filter(연도) + Card list | 제안: `All` · `2026` · `2025` · `2024`, 목록은 썸네일 + `Brand / 01` + 제목 |
| 3b | Design system | PageHead section ×3 + Card panel | 색(Semantic 토큰 견본), 글자(스타일 견본), 컴포넌트(이 하네스의 10개) |
| 4 | 끝 | Button ghost | `프로젝트 보드로 가기 ↗` → Projects |

## 5. 적용할 규칙

- Design system 탭의 견본 값은 **tokens.css를 그대로 읽어** 보여줍니다. 숫자를 따로 적지 않습니다.
- 목록 카드는 list 하나로 통일
- 연도 필터의 처음 선택은 `All`

## 6. 규칙에 없어서 정해야 하는 것 (담당자가 채우고 보고)

- 색 견본(색 네모 + 이름 + 값)은 새 컴포넌트가 필요한가, Card panel로 되는가
- 연도별 묶음 제목(연도 큰 숫자)을 PageHead section으로 할지

## 7. 규칙과 부딪힐 수 있는 것

- 연도 숫자를 크게 쓰고 싶을 때 → 숫자 전용 타입 스타일 없음. 보고.

## 8. 빈 상태

- 해당 연도에 작업이 없으면 `이 해에는 기록된 작업이 없습니다.` + `All 보기` Button ghost

## 9. 모바일

- Card list 1열, 썸네일 왼쪽 80×80
- 탭은 2칸 고정
